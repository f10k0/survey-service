# Сервис проведения опросов

Консольное приложение для создания опросов, регистрации
пользователей, прохождения опросов и просмотра статистики.

## Возможности

- создание опросов (тема и список вопросов);
- два типа вопросов: открытые (свободный ответ) и закрытые (выбор из вариантов);
- регистрация пользователей (имя, email, возраст);
- поиск опросов по подстроке в названии;
- отбор опросов по числу вопросов;
- сортировка опросов по числу вопросов;
- прохождение опроса: пользователь отвечает на готовые вопросы;
- защита от повторного прохождения;
- просмотр статистики по каждому ответу.

## Структура проекта

- `main.py` — точка входа, меню приложения;
- `surveys.py` — работа с опросами (добавление, поиск, сортировка);
- `users.py` — регистрация и поиск пользователей;
- `responses.py` — ответы и статистика;
- `storage.py` — сохранение и загрузка данных в JSON;
- `utils.py` — безопасный ввод (числа, строки, даты);
- `data/` — JSON-файлы данных (surveys, users, responses);
- `tests/` — автоматические тесты pytest.

## Основные сущности

- **Пользователь** — имя, email, возраст, статус регистрации.
- **Опрос** — название, тема, статус (активен / завершён / не начат), список вопросов.
- **Вопрос** — текст, тип (открытый / с вариантами), список вариантов.
- **Ответ** — пользователь, опрос, вопрос, выбранное значение.

## План развития

- **ПР3 (ООП)**: классы `User`, `Survey`, `Question`, `Answer`, методы для работы с сущностями.
- **ПР5–9 (Django)**: веб-интерфейс, PostgreSQL, модели и CRUD через админ-зону.
