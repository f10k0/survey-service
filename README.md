# Сервис проведения опросов

Консольное приложение для создания опросов, регистрации пользователей,
прохождения опросов и просмотра статистики.

## Назначение

Приложение позволяет:
- создавать опросы с открытыми и закрытыми вопросами;
- регистрировать пользователей;
- проходить опросы с проверкой возраста и защиты от повторного участия;
- хранить данные между запусками в JSON-файлах;
- просматривать статистику по ответам.

## Целевая аудитория

Организаторы опросов, преподаватели, HR-специалисты, маркетологи —
все, кому нужно быстро собрать и обработать мнения аудитории.

## Предметная область

Опрос — это набор вопросов по определённой теме, на которые
пользователь даёт ответы. Сервис хранит опросы, вопросы и ответы,
проверяет доступ пользователей и формирует статистику.

## Основные сущности

### Класс `Question` (модуль `models/questions.py`)

Представляет один вопрос опроса.

**Атрибуты:**
- `text` — текст вопроса;
- `options` — список вариантов ответа или `None`, если вопрос открытый.

**Методы:**
- `is_open()` — проверить, является ли вопрос открытым;
- `validate_options(options)` — статический метод, проверяет корректность
  вариантов ответа;
- `from_data(data)` — создать объект из словаря (метод класса);
- `to_dict()` — преобразовать в словарь для JSON;
- `__str__()` — строковое представление.

### Класс `Survey` (модуль `models/surveys.py`)

Представляет опрос — набор вопросов по одной теме.

**Атрибуты:**
- `id` — идентификатор опроса;
- `title` — название;
- `topic` — тема;
- `questions` — список объектов `Question`;
- `status` — статус (`активен` / `завершён` / `не начат`);
- `creation_date` — дата создания.

**Методы:**
- `questions_count` — свойство (`@property`), количество вопросов;
- `is_active()` — проверить, активен ли опрос;
- `add_question(question)` — добавить вопрос;
- `from_data(data)` — создать объект из словаря;
- `to_dict()` — преобразовать в словарь для JSON;
- `__str__()` — строковое представление.

### Класс `User` (модуль `models/users.py`)

Представляет пользователя сервиса.

**Атрибуты:**
- `id` — идентификатор;
- `name` — имя;
- `email` — email;
- `age` — возраст;
- `is_registered` — статус регистрации.

**Методы:**
- `is_adult(min_age, max_age)` — проверить, подходит ли возраст;
- `from_data(data)` — создать объект из словаря;
- `to_dict()` — преобразовать в словарь для JSON;
- `__str__()` — строковое представление.

### Класс `Response` (модуль `models/responses.py`)

Представляет ответ пользователя на вопрос конкретного опроса.

**Атрибуты:**
- `user` — объект `User`;
- `survey` — объект `Survey`;
- `question` — текст вопроса;
- `answer` — выбранный ответ.

**Методы:**
- `from_data(data, users, surveys)` — восстановить объект из JSON,
  найдя связанные `User` и `Survey`;
- `to_dict()` — преобразовать в словарь для JSON;
- `__str__()` — строковое представление.

## Взаимодействие объектов

- `Survey` содержит список объектов `Question`.
- `Response` хранит ссылки на объекты `User` и `Survey`,
  а не только их идентификаторы.
- Благодаря этому данные доступны напрямую:
  `response.user.name`, `response.survey.title`.

## Хранение данных

Данные хранятся в JSON-файлах каталога `data/`:

- `surveys.json` — список опросов с вопросами;
- `users.json` — список пользователей;
- `responses.json` — список ответов.

При загрузке JSON преобразуется в объекты классов,
при сохранении объекты преобразуются обратно в словари.
Связи в JSON хранятся через идентификаторы (`room_id`, `user_id`),
а в объектной модели — через ссылки на объекты.
