# Сервис проведения опросов

## Назначение
Приложение предназначено для организации и проведения опросов. Оно позволяет проверять доступ пользователей, собирать ответы, обрабатывать статистику и управлять опросами.

## Целевая аудитория
- HR-специалисты для опроса сотрудников
- Маркетологи для сбора мнения клиентов
- Организаторы мероприятий для обратной связи

## Предметная область
Опросы — это метод сбора данных. Пользователь проходит опрос, отвечая на вопросы. Система проверяет возраст, регистрацию и статус опроса перед допуском.

## Основные сущности
- **Пользователь**: имя, email, возраст, статус регистрации
- **Опрос**: название, тема, статус (активен/завершен/не начат), список вопросов
- **Вопрос**: текст вопроса, тип (один выбор/множественный), варианты ответов
- **Ответ**: пользователь, вопрос, выбранный вариант, дата ответа

## Основные функции
1. **Регистрация пользователя** — добавление нового пользователя в систему
2. **Создание опроса** — формирование опроса с вопросами и вариантами
3. **Проверка доступа** — анализ возраста и статуса регистрации перед прохождением
4. **Прохождение опроса** — пошаговый сбор ответов от пользователя
5. **Просмотр статистики** — подсчет голосов по каждому вопросу

## План развития
На следующих этапах планируется:

1. **ПР2 (коллекции и функции)**: 
   - Хранить опросы и ответы в списках/словарях
   - Реализовать функции для добавления вопросов и сохранения ответов

2. **ПР3 (ООП)**:
   - Создать классы User, Survey, Question, Answer
   - Реализовать методы для работы с сущностями

3. **ПР5-9 (Django)**:
   - Разработать веб-интерфейс на Django
   - Подключить PostgreSQL для хранения данных
   - Реализовать модели и CRUD через админ-зону

4. **ПР10-11 (Пользователи и API)**:
   - Аутентификация через Django Users
   - Создать REST API для мобильного приложения

5. **ПР13-15 (Тестирование и Docker)**:
   - Написать тесты на Pytest
   - Контейнеризация и CI/CD
